# Changelog

## 0.2.0 - 2026-11-03

### Changed

- **Licence: AGPL-3.0-only -> LGPL-3.0-only.** LGPLv3 is a set of additional
  permissions on top of GPLv3, so the package ships both texts: `LICENSE`
  (LGPLv3) and `COPYING` (GPLv3). Embedding `event-pump-web` in a site or app no
  longer places that site or app under copyleft. 0.1.0 stays under the terms it
  was distributed with; **0.2.0 is the first version carrying LGPL-3.0-only**.
- The SDK version reported in event context (`sdk.version`) advances to 0.2.0.
